# Assignment 4: Portfolio Website with CSS Flexbox

Jeremiah Morris-Wyley's portfolio (About Me page), rebuilt so the whole layout uses CSS Flexbox.

## Flex containers used
1. `body` – column layout for header / main / footer (sticky footer)
2. `.header-inner` – name on the left, navigation on the right
3. `.nav-list` – About | Portfolio | Contact links in a row
4. `.main-layout` – About Me content and the sidebar side by side
5. `.social-list` – GitHub, LinkedIn, and Stack Overflow icons in a row
6. `.contact-form` – stacked form fields (contact view)
7. `.site-footer` – centered footer text

The only float on the page is `.profile-img`, which wraps the About Me text around the headshot.
